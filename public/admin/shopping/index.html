      Add by voice from your phone

      The microphone button above works in Chrome on Android and in Safari on iPhone. For hands-free “Hey Siri”, set up a Shortcut once on each iPhone, using this key. The key only lets a phone add to and read this list. Nothing else on the site accepts it.

      iPhone — “Hey Siri, add to shopping”

      1. Open the Shortcuts app, tap +, and name the shortcut Add to shopping.
      2. Add the action Dictate Text. Set Language to English (UK) and Stop Listening to After Pause.
      3. Add Get Contents of URL. URL: https://myonlinehome.co.uk/api/shopping/voice. Tap the arrow to show more and set: Method POST; under Headers add Authorization with the value Bearer, a space, then the key; Request Body JSON, with one Text field called text set to Dictated Text.
      4. Add Speak Text and set it to speak Contents of URL. Siri then confirms what it added.
      5. Say “Hey Siri, add to shopping”, wait for the beep, then say the items: “milk, eggs and bread”.

      For “Hey Siri, what's on the shopping list”, make a second shortcut with just Get Contents of URL (same address and header, method GET) and Speak Text. Once the first one works, you can share it from the Shortcuts app to the other iPhone.

      Android

      1. Open this page in Chrome, tap ⋮, then Add to home screen. The list opens like an app.
      2. Long-press the icon and choose Add by voice. Then tap the microphone and speak.

      Google Assistant and Gemini can't send what you say to a website, so there's no true “Hey Google” route. The nearest is the free HTTP Shortcuts app: make a shortcut that sends a POST to the same address with the same header and a body of {"text":"…"}, taking the text from a prompt you answer with the keyboard microphone.
